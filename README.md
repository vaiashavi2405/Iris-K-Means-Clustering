# Iris K-Means Clustering 🌸

**Created by:** Vaishnavi Dawkhar

## About the Project

An interactive web application built using Streamlit that uses the K-Means Clustering algorithm to group Iris flowers based on their sepal and petal measurements.

## Features

* Enter sepal length, sepal width, petal length, and petal width.
* Predict the Iris flower cluster using a trained K-Means model.
* Display the corresponding Iris species.
* View cluster distance and standardized input values.
* Interactive and user-friendly interface.

## Technologies Used

* Python
* Streamlit
* Scikit-learn
* Pandas
* NumPy
* Machine Learning

## Dataset

The project uses the Iris dataset, which contains flower measurements such as sepal length, sepal width, petal length, and petal width.

## How to Run

1. Install the required libraries:
   `pip install streamlit pandas numpy scikit-learn`
2. Keep the required trained model `.pkl` files in the same folder as the Python application.
3. Run the application:
   `streamlit run app.py`
